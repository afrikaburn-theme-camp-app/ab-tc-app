# Support

## Questions

Use [GitHub Discussions](../../discussions) for questions about using or
contributing to the project.

## Something is broken

- **While using the app**: use the in-app reporter (the button in the
  bottom-left corner of any of the three apps) — it files the issue for you.
- **Otherwise**: [open an issue](../../issues/new/choose) and pick the
  template that matches.

## Security or privacy problem

**Never a public issue.** Report it privately per [`SECURITY.md`](SECURITY.md).

## What not to post

Never include real personal data — participants' names, contact details,
identity numbers, medical information — in an issue, discussion, or pull
request, even as an example. Use fictional data (see `AGENTS.md` §Cast, for
realistic copy) instead.
