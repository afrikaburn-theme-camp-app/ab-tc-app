# Member List

Parent document: [App Specification](app-specification.md)

Domains below are filled only from this corpus. Unknowns are left explicit.
Names marked **verify** come from meeting transcripts / notes and have not been
independently confirmed.

**Involvement Status is current only** — not an attendance history. Historical
participation lives in meeting minutes and Decision Records. A person may carry
more than one Involvement Status label (comma-separated). Each label is prefixed
with its colour signal. Optional short note after an em dash gives present-tense
context only.

### Theme Camp App team — Involvement Status labels

| Signal | Label | Meaning |
| --- | --- | --- |
| 🟢 | **Active — codebase** | Regularly contributes to the shared repo |
| 🟢 | **Active — product / docs** | Active on scope, specs, decisions, org liaison (not primarily code) |
| 🟢 | **Active — ops / domain** | Active on camp / ops / domain input |
| 🟡 | **Meetings only** | Present in calls / WhatsApp; not currently delivering work |
| 🔵 | **Recently joined** | Onboarded within roughly the last few weeks; orientation in progress |
| 🟠 | **Low capacity** | On the team but paused or limited for a known window |
| ⚪ | **Absent** | On the roster but not participating lately |
| 🔴 | **Departed** | Left; not current team |
| 🟣 | **Prospective** | Named; not onboarded |

### AfrikaBurn contacts — Involvement Status labels
