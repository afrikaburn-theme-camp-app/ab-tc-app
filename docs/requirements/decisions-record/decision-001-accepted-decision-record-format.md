# Decision 001

Parent page: [Decisions Record](../decisions-record.md)

Date: 2026-07-29

## Status

Accepted

## Context

We need to record the decisions made on this project and some decisions that have already been made.

## Decision

We will use Architecture Decision Records, with the template [described by Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).

We will drop the term “Architecture” from the name and call these Decision Records.

## Consequences

This is good because they will give a history and a context to decisions, helping us decide if we want to change past decisions.
